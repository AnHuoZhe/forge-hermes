# 大审标准

全部模块中审通过并锁定后执行。读取全量代码和架构文档。

## 检查清单

1. **功能验证**：核心功能端到端可用。
2. **架构一致性**：实现符合选定方案、分层和模块边界。
3. **契约检查**：跨模块接口、数据格式、错误处理和状态转换一致。
4. **测试覆盖**：核心路径加至少三个边界 case，并验证失败行为。
5. **数据流与失败模式**：按裁减表检查系统级流转和恢复策略。
6. **方案维度**：按方案规模裁减并报告上下文工程、记忆系统、工具调用、可靠性、运维隐患、成本控制、评估等维度。

## 边界

大审通过 → 锻造完成。不通过 → 必须改项映射到受影响模块，回退 build 重新实现和审查。
